# project3-Corner-Grocer
My first Journal in Git
# Project Summary
For this project, I created a C++ program called Corner Grocer Tracker. The program reads grocery purchase data from a file,
counts how many times each item was bought and displays the results. It helps store employees quickly view purchase frequencies and item trends.

#What I did well
I organized the program using a GroceryTracker class and used a map to store item frequencies. I also added input validation to help prevent user errors.

#Areas for Improvement
I could improve the program by making item searches case-insensitive and adding more error handling. 
These changes would make the program easier to use and more reliable.

#Challenges
The most challenging part was working with file input/output and maps. I overcame this by practicing, testing my code, and reviewing course materials.

#Tools and Resources
I used ZyBooks, course resources, C++ documentation, and Visual Studio to complete this project and strengthen my programming skills.
